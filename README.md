# Arad Sazan

A modern and responsive construction company website built with React and Vite.

Arad Sazan is a professional website designed for a construction company to present its services, introduce completed projects, and provide a simple way for users to request consultations.

The project focuses on a clean user interface, responsive design, and a smooth browsing experience across different devices.

## Overview

This website provides a digital presence for Arad Sazan with dedicated sections for company introduction, services, project portfolio, and contact information.

The design emphasizes modern layouts, Persian RTL support, optimized performance, and a professional presentation suitable for a construction brand.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Persian RTL layout support
- Modern landing page
- Company introduction section
- Services showcase
- Project portfolio section
- Contact and consultation form
- Smooth page navigation
- Optimized production build with Vite

## Technologies

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/nurollah-g/Arad-sazan.git
```

Go to the project directory:

```bash
cd Arad-sazan
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run on:

```
http://localhost:5173
```

## Production Build

Create an optimized production build:

```bash
npm run build
```

The generated files will be available inside the `dist` directory.

## Deployment

The project can be deployed on platforms such as Vercel.

Build command:

```bash
npm run build
```

Output directory:

